# Changelog

## 0.1.0 - 2026-10-20

First release, extracted from the calculation code behind the free calculators at https://cn8t.com/.

- Distributions: normal, chi-square, Student t, F, studentized range (Tukey), binomial, Poisson.
- Tests: one-sample and two-sample (Welch or pooled) t tests from summary statistics, exact binomial test.
- Power and sample size for t tests, two proportions and correlation.
- Least squares by Householder QR.
- Descriptive helpers: mean, standard deviations, quartiles (four methods), number-list parsing.
